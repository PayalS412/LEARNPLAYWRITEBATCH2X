# Learn Playwright Batch 2X

A comprehensive learning repository for Playwright automation testing, covering JavaScript fundamentals and Playwright basics.

## Table of Contents

### Chapter 1: Basic
- `01_Basic.js` - Introduction and basic setup
- `02_JS.js` - JavaScript fundamentals
- `03_JS_Commands.js` - Essential JavaScript commands
- `04_Hotcode.js` - Hot code examples

### Chapter 2: Javascript Concepts
- `05_JavascriptBasics.js` - Core JavaScript concepts for Playwright

### Chapter 3: Identifier & Literals
- `06_IdentifiersRules.js` - Identifier naming rules (Part 1)
- `07_IdentifiersRules2.js` - Identifier naming rules (Part 2)
- `08_Comments.js` - Comments in JavaScript
- `VS_Code_keyboard_shortcut_windows.md` - VS Code keyboard shortcuts for Windows

## Prerequisites
- Node.js installed
- Basic understanding of JavaScript

## Getting Started
1. Clone this repository
2. Run individual chapter files using Node.js:
   ```bash
   node Chapter01_Basic/01_Basic.js
   ```
